# CodeAlpha ProjectHub

A full-stack project management tool built using React, Node.js, Express.js and MongoDB.

## Features

- User authentication
- Create and manage projects
- Add team members
- Create and assign tasks
- Track task status
- Comment on tasks
- Responsive dashboard UI

## Tech Stack

- React
- HTML, CSS, JavaScript
- Node.js
- Express.js
- MongoDB
- JWT Authentication
